# Flutter Multi-Screen App

## 📱 Description
Application Flutter multi-écrans (thème recettes) démontrant :
- Navigation avec **GoRouter**
- Liste avec recherche/filtrage
- Écran de détail avec passage de paramètres
- Formulaire avec validation (3 champs)
- Gestion du thème clair/sombre
- Widgets réutilisables et responsive mobile/tablette

---

## 🚀 Fonctionnalités
- **4 écrans distincts** : Home, Liste, Détail, Formulaire
- **Navigation moderne** avec GoRouter
- **Recherche/filtrage** dans une liste de données
- **Détail dynamique** avec paramètres de route
- **Formulaire validé** (nom, email, mot de passe)
- **Thème clair/sombre** automatique
- **Widgets réutilisables** (`CustomButton`, `CustomCard`, `ResponsiveLayout`)
- **Responsive** mobile et tablette
